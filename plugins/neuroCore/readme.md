# О плагине

* @package     **{{package}}**
* @author      **SalesMan Team**
* @version     v.**{{version}}** от {{versiondate}}

**Нейроядро** — это «мотор» нейросетей для SalesMan CRM. Оно не пишет тексты само:
его задача — дать всем нейро-функциям (генерация писем, краткое описание сделки,
разбор звонков, ответы по базе знаний) один общий способ обращаться к модели.

Что это значит на практике: ключи, подключения, стоимость вызовов и очередь заданий
настраиваются один раз здесь, а не в каждом плагине отдельно. Подключили новую
нейросеть — ею сразу могут пользоваться все нейро-функции.

## Возможности

- **Подключение любых нейросетей.** Подходит любой сервис с OpenAI-совместимым API
  (OpenAI, DeepSeek, OpenRouter, Groq, Mistral, VseGPT), а для Google Gemini есть
  отдельный режим. Новая нейросеть добавляется настройкой, без обновления CRM.
- **Диагностика подключения.** Кнопка «Проверить» делает настоящий запрос и
  показывает модель, задержку, токены или дословную причину отказа: ключ, модель,
  адрес, квота.
- **Очередь заданий.** Долгие обращения к модели выполняются в фоне и не задерживают
  работу в CRM: задание переживает закрытие страницы и перезапуск сервера.
- **Учёт расхода.** Видно, сколько вызовов, токенов и денег ушло — по дням,
  сотрудникам, типам задач и моделям.
- **Кэш ответов.** Тот же самый вопрос не отправляется модели второй раз, поэтому не
  оплачивается повторно.
- **Журнал и оповещения.** Если подключение перестало работать или очередь встала,
  администраторы узнают об этом из уведомления, а не из жалоб сотрудников.
- **Защита данных клиентов.** Телефоны, почта, ФИО и реквизиты можно не отправлять
  провайдеру: вместо них модель увидит условные обозначения.

## Быстрый старт

1. Установите и включите плагин **Нейроядро** в разделе «Плагины».
2. Откройте раздел **Нейроядро** → **Подключения** и нажмите «Добавить подключение»:
   укажите название, тип, адрес API, модель и ключ.
3. Нажмите **Проверить**. Увидите ответ модели или понятную причину отказа.
   Учтите: проверка — это обычный платный запрос, он попадает в отчёт по расходу.
4. Включите галочку **Подключение активно** и сохраните.
5. Если планируете пользоваться очередью, установите плагин **Планировщик заданий** —
   задание для Нейроядра создаётся автоматически.

Готово: нейро-функции CRM теперь могут обращаться к модели.

## Разделы Нейроядра

| Раздел | Для чего |
|---|---|
| **Подключения** | Нейросети: адрес, модель, ключ, цены, ограничения |
| **Промпты** | Инструкции для модели: тексты, версии, проверка на примере |
| **Очередь** | Задания в работе и завершённые, их результаты и ошибки |
| **Расход** | Вызовы, токены и стоимость за выбранный период |
| **Журнал** | Что происходило: итоги заданий, отказы, очистка кэша |
| **Настройки** | Таймаут, повторы, кэш, сроки хранения, оповещения |

## Подключения

В одном подключении задаются:

- **Название** — как вы будете его узнавать в списке.
- **Тип** — OpenAI-совместимый API или Google Gemini.
- **Адрес API** — можно указать и корень сервиса, и адрес с версией.
- **Модель** — например, `deepseek-chat`.
- **Ключ** — вводится прямо в форме (см. «Где хранится ключ»).
- **Температура, максимум токенов, таймаут** — необязательные уточнения.
- **Режим JSON** — нужен, если ответ должен приходить в строгом виде. Не все сервисы
  это поддерживают: если появится ошибка про формат ответа, верните «Не использовать».
- **Цены и валюта** — нужны только для отчёта по расходу.
- **Разрешить отправлять персональные данные клиентов** — см. «Защита данных».

Подключений может быть несколько — например, дешёвая модель для массовых задач и
сильная для сложных. Включённые подключения сразу доступны нейро-функциям CRM.

## Где хранится ключ

Способ выбирается в самом подключении.

### Хранить в CRM (по умолчанию)

Ключ вводится в форме и сохраняется в базе **в зашифрованном виде**. В интерфейсе он
больше не показывается — только маска вида `sk-4d34…8d42`. Новое значение заменяет
старое; пустое поле при изменении оставляет ключ прежним. На сервер ходить не нужно,
подключение настраивается прямо из CRM.

> **Важно для резервных копий.** Вместе с базой нужно копировать и служебный файл
> плагина с ключом шифрования. Если восстановить только базу, сохранённые ключи не
> расшифруются: Нейроядро прямо скажет об этом в списке подключений, и ключ придётся
> ввести заново.

Чего это не даёт: защиты от полного доступа к серверу — тот, кто видит и базу, и файлы
сервера, получит ключ.

### Переменная окружения сервера

Ключ в CRM не хранится вообще — в базе остаётся только **имя** переменной. Вариант
строже, но требует доступа к настройкам сервера.

**Apache** — в `.htaccess` сайта или в настройках виртуального хоста:

```
SetEnv DEEPSEEK_API_KEY sk-xxxxxxxxxxxxxxxx
```

**nginx + php-fpm** — в настройках пула:

```
env[DEEPSEEK_API_KEY] = sk-xxxxxxxxxxxxxxxx
```

**Для всей системы** — в файле `/etc/environment` (потребуется перезапуск PHP):

```
DEEPSEEK_API_KEY=sk-xxxxxxxxxxxxxxxx
```

**ISPmanager / cPanel** — раздел управления переменными окружения домена.

В поле вводится только имя переменной. Если вставить туда ключ целиком или строку
`ИМЯ=значение`, Нейроядро это распознает: в поле останется имя, а рядом появится
готовая строка для сервера.

После изменения переменной перезапустите PHP: в форме появится список переменных,
которые PHP видит. Затем нажмите «Проверить».

## Промпты

**Промпт** — это инструкция для модели с переменными вида `{{client}}`, которые
подставляет CRM. Промпты принадлежат нейро-функциям, а не ядру.

- Плагин приносит свои промпты и регистрирует их при активации.
- **Ваши правки не перезаписываются.** Если плагин позже обновит свой текст, в списке
  появится пометка «в плагине другой текст», а сохранённый вариант останется: решение
  принимаете вы, а не программа.
- У промпта есть версии и кнопка проверки на примере — можно посмотреть, что ответит
  модель с вашими данными, и сохранить только удачный вариант.

## Очередь заданий

Ответ модели приходит за секунды, а иногда за десятки секунд, а массовая операция —
это сотни вызовов. Держать такую работу в открытой странице нельзя, поэтому задания
выполняются в фоне.

- **Задания не дублируются:** одинаковые задания (тот же промпт, версия, данные и
  автор) не встанут в очередь второй раз, пока первое не завершено. Двойной клик не
  оплачивается дважды.
- **Задание не теряется.** Если сервер перезапустился или фоновая задача была
  прервана, через 15 минут задание вернётся в очередь и будет выполнено.
- **Повтор только по делу.** Занятость сервиса, сбои на стороне провайдера, таймаут и
  обрыв сети повторяются с растущей паузой; отказ по ключу или по правилам провайдера
  не повторяется — это только тратило бы деньги.
- **Отмена** возможна, пока задание не начало выполняться. Задание в работе отменить
  нельзя: запрос уже отправлен и будет оплачен.
- **Уведомление** об окончательной ошибке придёт в «колокольчик» автору задания
  всегда, об успехе — если задание поставлено с уведомлением.

Статусы заданий: **в очереди**, **в работе**, **выполненные**, **с ошибкой**,
**отменённые**.

Если планировщик на сервере не запущен, задания будут копиться и не выполнятся сами:
вкладка «Очередь» предупредит об этом, а разобрать очередь вручную сможет ваш
системный администратор.

Переменные задания (данные CRM, которые подставлялись в промпт) удаляются после
успешного выполнения — чтобы данные клиентов не оставались в очереди. У заданий с
ошибкой они сохраняются: без них причину не разобрать. Хранить их всегда можно,
включив соответствующую настройку.

## Кэш ответов

Кэш экономит деньги: буквально тот же вопрос не отправляется модели второй раз, ответ
берётся из сохранённых. В интерфейсе такой ответ помечается как «взято из кэша» и в
расход не попадает. Изменились данные — изменился вопрос, ответ будет свежим.

Срок жизни кэша задаётся в настройках (по умолчанию 60 минут). Значение `0` выключает
кэш полностью.

## Цены и отчёт по расходу

Стоимость считается **только по ценам, которые вы указали в подключении**. Нейроядро
не знает прайс чужой модели и не выдумывает его: если цены не заданы, в отчёте будут
точные токены, а сумма останется пустой.

| Поле | Что означает |
|---|---|
| Цена за 1 млн входных | сколько стоит миллион входных токенов |
| Цена за 1 млн выходных | сколько стоит миллион выходных токенов |
| Плата за вызов | фиксированная плата за сам запрос, независимо от токенов |
| Валюта цен | метка валюты (`₽`, `$`) — чтобы отчёт не складывал разные валюты |

**Цены указываются за миллион токенов.** Прайс VseGPT опубликован за 1000 токенов,
поэтому его значения умножаются на 1000: `deepseek/deepseek-chat` стоит 0.05 / 0.15 ₽
за 1000 → в подключении указывается **50** и **150**.

**Плата за вызов нужна не всегда.** Её берут онлайн-модели VseGPT: Perplexity Sonar —
0.85 ₽ за поисковый запрос. Эта плата больше стоимости токенов на два порядка, поэтому
без неё отчёт по такому подключению занижал бы расход почти до нуля.

**Валюта предохраняет от бессмысленного итога.** Если в одном периоде есть цены в
рублях и в долларах, отчёт покажет суммы отдельно по каждой валюте и прямо напишет,
почему нет одного числа.

Учитывается **каждый** вызов, который вернул токены: из очереди, из интерфейса, от
нейро-функций и от кнопки «Проверить». Попадание в кэш не оплачивается и в расход не
попадает.

## Защита данных клиентов

В подключении есть переключатель **«Разрешить отправлять персональные данные
клиентов»**. По умолчанию он включён: промпт уходит провайдеру как есть.

Если галочку снять, Нейроядро заменит телефоны, почту, ФИО и реквизиты условными
обозначениями вида `[PHONE_1]`, а в ответе модели подставит настоящие данные обратно:
модель видит структуру письма, но сами данные остаются в CRM. Каждая такая отправка
отмечается в журнале — без самих значений.

Границы честности: названия компаний, должности и текст переписки не маскируются — по
ним клиент всё ещё узнаваем. Это защита от утечки реквизитов, а не полная анонимизация.

## Журнал

Журнал отвечает на вопрос «что вообще происходило»: итоги заданий, отказы
подключений, очистка кэша, маскирование данных. Текстов промптов и ответов модели
здесь нет — только служебные сведения; полный ответ задания виден в его карточке.

Есть фильтры по уровню (подробно, информация, предупреждение, ошибка), периоду и
номеру задания. Срок хранения журнала задаётся в настройках (по умолчанию 30 дней),
а удалить старые записи можно и вручную, кнопкой.

## Оповещения

Нейроядро сообщает администраторам о том, что иначе осталось бы незамеченным:

- подключение не работает: ключ отозван, не задана переменная окружения, ключ не
  расшифровывается или нет ни одного включённого подключения;
- очередь не разбирается — обычно это значит, что не запускается планировщик.

Оповещения приходят в «колокольчик» и попадают в журнал. Одно и то же не повторяется
чаще, чем указано в настройках (по умолчанию — раз в 6 часов). Для отправки
уведомлений во внешние каналы (Telegram, Viber) нужен отдельный модуль интеграции.

## Виджет рабочего стола

Виджет **«Нейроядро: очередь и расход»** показывает состояние очереди, расход за
сегодня и последние ошибки. Он доступен **только администраторам** — и в списке
виджетов, и на рабочем столе.

Включить его можно в разделе **Мои настройки** → **Виджеты**.

## Настройки

| Параметр | По умолчанию | Что делает |
|---|---|---|
| Таймаут запроса, сек | 30 | сколько ждать ответ модели (5…300) |
| Попыток при ошибке | 3 | сколько раз повторить временный сбой (1…10) |
| Кэш ответов, минут | 60 | срок жизни кэша, `0` — выключить |
| Хранить журнал, дней | 30 | `0` — хранить бессрочно |
| Хранить задания, дней | 30 | срок хранения выполненных заданий, `0` — бессрочно |
| Оповещать об очереди, заданий | 50 | порог, после которого приходит оповещение, `0` — не оповещать |
| Повтор оповещения, минут | 360 | не чаще какого интервала повторять одно и то же оповещение |
| Сохранять переменные задания после выполнения | выключено | включено — переменные остаются и после успеха; выключено — данные CRM из очереди удаляются |

## Инструкция для разработчиков

Если вы делаете свой плагин и хотите пользоваться нейросетью, не заводя второй
ключ и второй отчёт о расходе, — нажмите **Инструкция для разработчиков** в шапке
раздела. Откроется отдельное окно с руководством по программному интерфейсу
Нейроядра: подключение классов, реестр промптов, вызов модели, очередь заданий,
разбор JSON-ответов, учёт расхода, безопасность — с примерами кода целиком,
вплоть до небольшого плагина.

Руководство открывается только администратору: оно описывает внутреннее
устройство ядра. Текст лежит в файле `plugins/neuroCore/developers.md`.

## Требования

- SalesMan CRM 2025.2 и выше
- PHP 7.2 … 8.1
- Исходящий доступ в интернет по HTTPS к API выбранной нейросети
- Плагин **Планировщик заданий** — чтобы очередь разбиралась автоматически

## Типовые проблемы

| Что видно | Причина | Что делать |
|---|---|---|
| «Переменная окружения не задана» | ключ не проброшен в PHP | задать переменную и перезапустить PHP |
| «Ключ отклонён» | ключ неверный или отозван | проверить значение ключа у провайдера |
| «Адрес или модель не найдены» | опечатка в адресе API или имени модели | уточнить адрес и название модели в кабинете провайдера |
| «Превышена квота» | закончились средства или лимит запросов | проверить лимиты и баланс у провайдера |
| «Истёк таймаут» | нет исходящего доступа к сервису | проверить сеть и файрвол сервера; при медленной модели увеличить таймаут |
| Задания копятся, но не выполняются | не работает планировщик | проверить плагин «Планировщик заданий» |
