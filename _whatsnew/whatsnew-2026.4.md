# Версия - 2026.4 (Relise)
#### от 10.11.2026 (build 10112026)

## Критично

- Переход на PHP 8.3+ (версии PHP < 8.3 не поддерживаются) из-за критических проблем в ядре PHP (CVE-2026-109618/619), которые устраняются только с версии 8.3
- API v.1.0 убран из дистрибтива и больше не поддерживается
- API v.2.0 убран из дистрибтива и больше не поддерживается
- Обновлен дистрибутив с веб-сервером. Теперь он базируется на Open Server 6.5.1 (управление сильно изменилось) с PHP 8.5.12, которая содержит фикс для CVE-2026-109618/619
- Обновлен Adminer до версии 6.2.0
- Рекомендуемая версия MySQL 8.0+, поддержка старых версий не предусмотрена

## Исправления

- Безопасность:
  - проведен аудит безопасности приложения, внесены исправления для повышения безопасности и защиты данных
- Действия: Смена ответственного - исправлена опция передачи напоминаний
- Настройки: Поля по этапам - исправлена ошибка в определенных ситуациях
- Закрытие сделки: +блок Напоминания
- Экспресс-форма: исправление двойного открытия карточки сделки
- Почтовик:
  - исправлена работа с прикреплением локальных файлов при написании писем
- Отправка почты:
  - добавлена поддержка случаев, когда login != email почтового ящика
